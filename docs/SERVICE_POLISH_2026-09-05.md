# 2026-09-05 서비스 완성도 정리

사용자 요청에 따라 공개 서비스에서 과한 홍보 문구, 장식, 반복 설명을 줄였다. 모델링 기능과 외부 이용 경로를 중심으로 정리했다.

## 화면 변경

- 공개 홈: 배경 이미지와 큰 환영 장면을 없애고 서비스명·실제 분석 예시·사례 목록을 배치했다. ‘모델링 결과 살펴보기’와 ‘서비스 소개’를 바로 제공한다.
- 서비스 소개: 목적, 전체 과정, 사용자/운영자 5단계 흐름, 현재 제공 범위를 짧은 문서 형태로 정리했다. 별도의 홍보 문구와 중복 점수 카드는 제거했다.
- 사업 분석: 큰 이미지 헤더·장식 배지·탭 번호를 제거했다. 원천자료·변수·평가 반영·평가기준 등 실제 작업 이름으로 바꿨다.
- 분석 요약: 두 축 결과를 먼저 놓고 항목별 배점을 행으로 정리했다. 매출 감소 사례 비교는 표로 바꾸고 중복 원문 이야기 카드를 없앴다.
- 변수: 전체 검색 표를 앞으로 이동했다. 검색 결과 없음과 사례 로딩 상태를 표시한다. 화면 값에서 true/false·MISSING 등의 중복 코드를 줄이고 필요한 변수 코드는 상세 조회에 남겼다.
- 평가 반영: 입력 모드 선택을 작게 정리했다. 산식·분모·제외 항목은 유지하며 같은 내용을 여러 번 경고하지 않는다.
- 입력 체험: 큰 골목 간판과 비어 있는 왼쪽 공간을 없앴다. 입력 양식을 가운데 배치하고 제목을 ‘기본 정보’, ‘답변 방식 선택’으로 바꿨다.
- 공통: 공개 화면의 서체·배경·탐색 메뉴·색상을 통일했다. 평가 근거 창에서는 키보드 초점이 창 밖으로 빠져나가지 않게 했다.

## 기능 경계

AI 처리 동의, 사용 공급자 안내, 합성 사례 표시, 미확인 상태, 평가 산식, 방문자별 기록 격리는 유지한다. 실제 점수 규칙을 바꾸거나 예측 성능을 새로 주장하지 않는다. 소유자 서비스의 인증은 변경하지 않았다.
