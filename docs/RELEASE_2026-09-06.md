## 변경 내용

기획안의 자료·신용정보 확인 → 변수화 → 평가 → 목표·수행기록 → 재평가 → 기관 검토 준비 흐름을 공개 서비스에 연결했다. 등록된 합성 시연의 최종 답변은 기존 Python 모형으로 계산하며, 일반 상담에는 합성 거래자료를 연결하지 않는다.

- 초기 화면에 서비스 소개와 평가 사례를 배치하고, 사용자·운영자 흐름을 한 페이지로 설명한다.
- 94개 변수의 출처·값·상태, 항목별 배점과 제외 분모, 6개월 수행자료와 재평가 근거를 확인할 수 있다.
- 가입·Google 로그인 없이 열람·체험하며 방문자별 상담 기록을 격리한다. AI 처리 동의는 직접 선택한다.
- 담당자 화면은 사업·행동 점수를 먼저 보여 준다. 답변 품질·내부 변수·측정 규격은 상세 영역으로 정리하고 품질 산정과 사업 점수의 명칭을 구분했다.
- 영업일 감소 사유·해소 상태, 목표 단위·측정 자료를 한글로 표시한다. 과도한 장식·이야기식 문구와 반복 안내를 줄였다.
