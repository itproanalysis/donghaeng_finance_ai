대상은 `https://donghaeng-finance-review-jy5k5cvnjq-du.a.run.app`이다. 기존에 수정 중인 저장소의 작업을 보존하고 공개 서비스의 이용 장벽과 검토 동선을 개선했다. 소유자 전용 `donghaeng-finance-ai`의 Google IAP와 운영 자료는 이번 배포 대상이 아니다.

## 반영 내용

- 공개 홈의 주 진입을 ‘모델링 결과 살펴보기’로 바꿨다. ‘서비스 소개’ 버튼에서 목적·6단계 전체 과정·사용자/운영자 5단계 Flow·현재 구현 범위를 한 페이지로 확인한다.
- ‘평가 반영’ 탭을 추가했다. 정형 데이터만/맥락 변수 결합을 선택하면 해당 사례의 Python 재계산 결과를 전환한다. 10개 사례 모두 비교를 생성하며, 정형 변수 48개가 같음을 검사한다.
- 두 축 점수에 합계 배점·환산 분모·산출 항목 비율·제외 항목을 표시한다. 항목별 100점 환산 구성을 그리되 변수 중요도나 인과 기여도로 표시하지 않는다.
- 10개 평가항목의 전후 배점·구간·포함 여부를 대조한다. 94개 변수 검색에서 값·원문·연결된 평가항목과 함께 사용하는 변수를 확인한다.
- 기존 모델 평가 탭의 비교가 항상 영업일 감소 사례를 가리키던 문제를 고쳤다. 이제 현재 선택 사례의 전후 결과를 사용한다.
- 영업일 사례의 개선가능성은 기존 규칙 그대로 40→67.5, 산출 분모는 60→80이다. 규칙이나 배점을 수정해 점수 상승을 만든 것이 아니다.
- 결측 변수 보존과 0점 규칙을 구분했다. 영업일 감소 사유 미확인·목표 미정이 현재 규칙에서 0점 구간이라는 한계를 명시한다.
- 공개 홈에서 ‘가입 없이 바로 체험’으로 이동하면 가상의 호칭·카페 업종만 준비한 상태에서 직접 채팅 또는 음성을 선택한다. 실제 사업 수치와 답변은 미리 넣지 않는다.
- 직접 가게를 입력하는 경로는 공개 모드에서 환영 화면을 한 번 덜 거친다. 별칭 사용을 안내하며 기존 직접 입력·업종 선택 경로도 제공한다.
- AI 처리 동의는 기본 선택하지 않는다. 음성을 선택하지 않아도 채팅으로 진행할 수 있다. 소유자 전용 서비스에서는 체험 쿼리로 기본 정보를 채우지 않는다.
- 인터뷰 생성 후 동의 저장 재시도는 동일 프로필의 생성된 ID를 재사용한다. 이중 클릭은 요청 전에 차단한다.
- 늦게 도착한 401 응답이 이미 생성된 방문자 세션을 다시 교체하지 않도록 수정했다. 쿠키가 저장되지 않으면 재시도를 반복하지 않고 원인과 분석 열람 경로를 안내한다.
- 공개 분석 화면은 방문자 세션을 만들지 않는다. 읽기 전용 분석에서 방문자 생성 한도를 소비하지 않는다.
- 요약 첫 부분에 두 축 산식과 평가 반영 진입을 놓고, 이어 같은 -20% 매출 하락의 세 원인을 비교한다. 원인 코드는 한국어로 표시한다.
- 전체 8단계 과정은 펼쳐 볼 수 있다. 선택한 분석 탭은 URL에 반영되어 공유·새로고침·뒤로가기 시 복원된다.
- 현재 사례의 근거 JSON을 내려받고, 사례·탭 링크를 복사할 수 있다. 클립보드가 차단되면 복사할 주소를 표시한다.
- 탭의 키보드 이동·다음 단계 안내·직접 인터뷰 연결을 제공한다.
